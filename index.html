Sobre mí 👤

Empecé trasteando con ordenadores por curiosidad y acabé administrando servidores Linux, montando servicios web y automatizando tareas repetitivas. Me gusta entender cómo funciona todo "por debajo": redes, sistemas operativos, contenedores, métricas y seguridad.

Suelo trabajar con Python para automatización y desarrollo de herramientas, Bash para scripts rápidos y Docker para desplegar entornos aislados y reproducibles. Me interesa especialmente la combinación de administración de sistemas + desarrollo, es decir, ser capaz de diseñar, desplegar y mantener una solución de principio a fin.

A nivel de metodología, doy mucha importancia a:

  • Documentar lo que hago para que otros puedan entenderlo y reutilizarlo.
  • Automatizar tareas manuales y repetitivas para reducir errores.
  • Monitorizar servicios con métricas, logs y alertas claras.
  • Seguridad y buenas prácticas en red, permisos y exposición de servicios.

Me motiva especialmente participar en proyectos donde pueda aportar estabilidad a la infraestructura, mejorar tiempos de despliegue y simplificar el mantenimiento del día a día.

Mis Proyectos 📂

Estos son algunos proyectos que he desarrollado y mantengo en GitHub. Todos surgen de necesidades reales: automatizar tareas, procesar grandes volúmenes de datos o facilitar el despliegue de servicios. Cada repositorio incluye código, documentación y ejemplos de uso.

Tools 0Vinylo0 Colección de herramientas web que uso y mantengo para tareas de administración, automatización y utilidades del día a día. Incluye utilidades para redes, gestión de archivos, pruebas de servicios y pequeños paneles creados a medida.
My Script Herramienta en Python pensada para mantener sincronizados scripts locales con GitHub. Permite subir cambios de forma automatizada usando cron, registrar ejecuciones y tener siempre una copia de respaldo del código que utilizo en servidores y entornos de pruebas.
Iterando Pares Scraper avanzado desarrollado en Python para extraer información e imágenes del portal PARES. Incluye control de errores, paginación, almacenamiento de resultados y lógica específica para recorrer enlaces relacionados. Está pensado para trabajos de análisis y archivística.
Iterando Pares Docker Versión contenedorizada del scraper de PARES. Usa Docker, Redis y Tor para gestionar grandes volúmenes de URLs, mejorar el anonimato y distribuir el trabajo. Ideal para ejecutar el scraping en servidores de forma controlada y escalable.
Proyecto Mercantil Marker Proyecto orientado al tratamiento de documentos. Integra herramientas como rclone y Marker para convertir archivos, sincronizarlos con almacenamiento en la nube y mantener una estructura ordenada. Resulta útil para flujos de trabajo donde se manejan muchos PDFs y se requiere procesarlos de forma automática.

Todos estos proyectos están en constante evolución. Me gusta mejorarlos a partir del uso real, añadiendo opciones de configuración, manejando más casos límite y documentando los pasos para que cualquiera pueda montarlos en su propio entorno.
